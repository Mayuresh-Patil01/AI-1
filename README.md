# AI Project

A personal AI project — idea still being decided.

## Working across PCs

This repo is the single source of truth, synced via GitHub.

- **Before starting work:** `git pull`
- **When done:** `git add .` → `git commit -m "describe change"` → `git push`

## Secrets

API keys and other secrets go in a `.env` file, which is git-ignored and must never be committed.
Copy `.env.example` (once it exists) to `.env` on each PC and fill in the values.
